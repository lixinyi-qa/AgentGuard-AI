# 威胁模型

## 资产与信任边界

受保护资产包括工具调用权限、虚构客户对象、幂等状态、审批状态、Trace、策略版本、环境凭据和报告真实性。用户输入、知识文档、可选模型输出、工具返回值和外部依赖都视为不可信；Policy Engine 是工具执行前的强制边界。

## 主要威胁与控制

| 威胁 | 示例 | 控制 | 剩余风险 |
|---|---|---|---|
| 直接提示词注入 | 忽略系统要求 | 输入模式检测、零工具拒绝、POL-007 | 同义改写可能漏检 |
| 间接提示词注入 | 知识文档要求修改联系方式 | 恶意标记、检索内容无权限、输出检测 | 规则检索与模式均有漏报 |
| 对象级越权 | 客户 A 查询客户 B | owner 映射、POL-002/POL-010、失败关闭 | 真实系统需可信授权服务 |
| Excessive Agency | 跳过审批直接退款 | 高金额阈值、人工审批工具、写操作审计 | 阈值配置错误仍可能放大风险 |
| PII/Secret 外泄 | 手机、邮箱、身份证、Key | 输入拒绝、递归脱敏、最终回答扫描 | 正则无法覆盖所有秘密格式 |
| 重复写入 | 超时重试造成双退款 | 写工具不自动重试、幂等记录、冲突 409 | 跨服务幂等需分布式一致性 |
| 恶意/脏工具结果 | 缺字段、错误类型、注入文本 | 输出 Schema、安全检查、安全失败 | Schema 只验证本项目声明字段 |
| 依赖不可用 | 429、500、DB/权限服务故障 | 有限重试、最多 3 次、安全降级 | 本地故障模型不等同真实网络 |
| 证据篡改 | 修改本地 SQLite/报告 | CI 重新生成、run/trace ID、Git 历史（发布后） | 当前无签名/WORM 存储 |

## STRIDE 简表

- Spoofing：角色字段只是演示身份；真实系统必须接入强认证。
- Tampering：本地数据库可被有文件权限的人修改。
- Repudiation：有审计事件，但未签名。
- Information Disclosure：脱敏和密钥扫描降低风险，不能证明零泄漏。
- Denial of Service：有限重试；没有生产限流或熔断。
- Elevation of Privilege：角色 + 对象 + 撤销授权共同约束。

本项目是教育演示，不构成金融安全评估或监管合规结论。
